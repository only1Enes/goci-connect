# Security Policy

## Supported Versions

Goci Connect has not published its first stable release. Security fixes are applied to the default branch. After releases begin, this table will identify the supported release lines.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Unreleased snapshots and forks | No |

## Reporting a Vulnerability

Report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/only1enes/goci-connect/security/advisories/new). Do not open a public issue or include credentials, tokens, authorization codes, client secrets, or personal data in a report.

Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Reports should receive an acknowledgement within three business days and an initial assessment within seven business days. Timelines for a fix and coordinated disclosure depend on severity and complexity.

Please allow maintainers a reasonable opportunity to investigate and release a fix before public disclosure.
